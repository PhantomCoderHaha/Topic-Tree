Topic Tree

Keeps your main line of thought visible while you research. Every search and page you visit lands on a tree, like a git graph. You tell it when you go off on a tangent, and it shows you the way back.

Start in 30 seconds

  1. Pin the icon: puzzle piece in the toolbar → pin Topic Tree. Click it to open the tree on the right.
  2. Just browse. Recording is on: searches and pages are added to the branch you're on. You don't need to press anything.
  3. Going off on a side question? Press t in the tree (or Ctrl+Shift+Y then t on any page). You're now on a tangent.
  4. Done with the side question? Press m to return to your main branch. The tangent folds away into one line.
  5. Forgot to mark it? In the tree press v, move with j/k over the pages that were a detour, then press t.
  6. Want to go back to something? Double-click any node to reopen that search or website (or click it once and press Enter).
Every node is a way back. Double-click a search (○) to rerun it, or a page (●) to reopen it, in the current tab. For a grouped site node (▸ ×3), unfold it and double-click the exact page you want. Going back this way isn't recorded, so it won't clutter your tree. A single click only selects the row (for renaming, marking and so on).

Without leaving the page

Press Ctrl+Shift+Y, then one key: t tangent · u up a level · m back to main · n new topic · b previous branch. A small hint appears at the bottom of the page while it waits for your key. Change the shortcut at brave://extensions/shortcuts.

Keys in the tree

Click inside the tree first so it has the keyboard. Everything also works with the mouse.

tStart a tangent from where you are (a temporary detour)
uUp one level: close this tangent and go back to the branch it came from (for a tangent inside a tangent)
mReturn to the main branch, however deep you are
nNew topic: a new main branch, for a complete change of subject. Changed your mind before searching? m takes you back and the empty topic disappears (the same goes for a tangent you haven't used yet).
b or `Back to the previous branch you were on (press again to go further back)
fJump: every branch gets a letter label; type it to go there
/Find a branch or page by name; ↑↓ then Enter
j kMove down / up · g top · G back to the newest
EnterOpen the page under the cursor (double-click works too; on an unfolded page row it opens that exact page). Re-opening from the tree is a revisit: it isn't added to the tree.
h lFold / unfold a tangent (or click its ↳ line), and a grouped site node: click its ▸ ×3 to see every page in it
r / eName the branch / the page under the cursor
sSplit: pages on one site share a node. Unfold it (▸ ×3), put the cursor on a page and press s: that page and the ones after it become their own node. On the node itself, it splits off the last page.
vSelect past pages (j/k), then t = it was a tangent, p = it was a tangent of another branch (type that branch's label), m = it wasn't a tangent after all (move back to main), n = it was a new topic. Shift-click also selects.
zBranch view: just the branches, for an overview
?Key list · Esc cancels anything

The buttons at the top

?Opens this guide
☰Sessions: resume an earlier tree, or start a new one. Manage history… opens a full list where you can search and delete past sessions (one, several, or all).
⚙Settings: when the drift alarm fires; whether saving to disk is connected
−Hide: the tree disappears but keeps recording. Click the icon to bring it back where it was.
❐ □Float as a small card over the page, which you can drag by its top edge / dock it back to the side
✕Stop recording this session (asks first). The tree is kept. Click the icon to record again; it then shows off until you do.

Reading the tree

● filled dotA page you visited (×3 = 3 pages on that site in a row)
○ ringA search (“in quotes”)
Lane on the rightA tangent; the dashed line shows where you came back
↳ lineA finished tangent, folded. Click it to unfold.
Glowing dotWhere you are now
Dashed ringA branch you just started (t or n): your next search or page goes there. Leave it unused and it disappears.

The drift alarm

When a tangent reaches a number of steps or minutes (set in ⚙), a banner asks if you want to return to your main topic. Return takes you back; Keep going hides it for this tangent.

History

☰ → Manage history… opens every past session, grouped by day. Works fully with the mouse:

Click a sessionSelect it (Shift-click selects a range; Select all / Clear at the top)
OpenContinue that session's tree in this window (double-click works too)
Delete / Delete selectedRemoves the session from Topic Tree and its saved files. Always asks first; can't be undone.
Search boxFilter by name

Keyboard: / search · j k move · x select · Enter open · Delete delete.

Where your data goes

Only on this computer. Each session is saved to %LOCALAPPDATA%\TopicTree\sessions\ as <session>.jsonl (every event) and <session>.tree.json (the tree), so you can analyse it later. Nothing is sent anywhere.

The floating card can't appear on browser pages like the New Tab page or settings. Open a website first.
